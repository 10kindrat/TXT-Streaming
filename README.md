# TXT 스트리밍

`.txt` 파일에 담긴 미디어 URL(이미지/영상)을 브라우저에서 바로 스트리밍하는 순수 HTML/CSS/JS 뷰어입니다.  
서버 없이 파일을 열기만 하면 동작합니다.

---

## 파일 구조

```
text-viewer/
├── index.html   ← 여기를 브라우저로 열면 됩니다
├── style.css
├── app.js
└── README.md
```

---

## 사용법

1. `index.html`을 브라우저(Chrome 권장)로 열기
2. **폴더 선택** 또는 **ZIP 업로드** 또는 **텍스트 붙여넣기**로 스캔 결과 불러오기
3. 폴더 → TXT 파일 순서로 펼쳐서 미디어 확인

---

## 기능

### 미디어 보기
- 이미지 / 영상 썸네일 그리드 (XS ~ XL 5단계 크기 조절)
- 폴더 구조 2단계 유지 (그룹 폴더 → TXT 파일)
- 드래그 앤 드롭 지원
- ZIP 파일 직접 업로드 지원

### 즐겨찾기
- 카드의 ★ 버튼으로 개별 미디어 즐겨찾기
- TXT 파일 헤더의 ★ 버튼으로 파일 내 전체 미디어 일괄 즐겨찾기/해제
- 즐겨찾기 탭에서 파일별로 모아보기
- 이미지 / 동영상 필터
- `localStorage`에 자동 저장 (새로고침·재시작 후에도 유지)

### 모달 — 데스크탑
| 키 | 동작 |
|---|---|
| `E` / `→` | 다음 미디어 (파일 경계 자동 넘김) |
| `Q` / `←` | 이전 미디어 (파일 경계 자동 넘김) |
| `F` | 즐겨찾기 토글 |
| `Space` | 영상 재생/일시정지 |
| `D` / `A` | 영상 +1초 / -1초 |
| `W` / `S` | 영상 +5초 / -5초 |
| `ESC` | 닫기 |

### 모달 — 모바일
| 제스처 | 동작 |
|---|---|
| 왼쪽으로 스와이프 | 다음 미디어 |
| 오른쪽으로 스와이프 | 이전 미디어 |
| 아래로 스와이프 | 닫기 (메인 화면으로) |

- 영상이 화면에 꽉 차게 표시 (크기 통일, 조작 편리)
- 파일 경계를 자동으로 넘겨 전체 미디어를 연속으로 탐색

## 참고

- 수집한 미디어 URL / 콘텐츠 자체는 저작권이 있을 수 있으므로 저장소에 포함하지 마세요.
- 이 뷰어 코드(HTML/CSS/JS)는 자유롭게 사용·수정·배포 가능합니다.
- CORS 정책으로 일부 이미지가 로드되지 않을 수 있습니다 (카드에 `CORS` 표시).
